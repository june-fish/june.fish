# [june.fish](https://june.fish)

## Git Submodules for Theme

This uses Git submodules to install the [Anatole Theme](https://github.com/longfangsong/anatole-zola).

Clone repository with submodules:
```sh
git clone --recurse-submodules git@github.com:june-fish/june.fish.git
```

Update submodules after you have cloned:
```sh
git submodule update --init --recursive
```
